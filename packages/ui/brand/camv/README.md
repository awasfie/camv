# Camv Brand Assets — Version 1.0

This package contains the **approved Camv identity system**: the Human Alignment emblem, the outlined Noto Sans Bold wordmark, and the final light, dark, monochrome, favicon, and app-icon files.

## Package map

| Folder | Contents |
| --- | --- |
| `logo/svg/` | Production SVG lockups and master emblem. The wordmark is converted to vector paths. |
| `logo/png/` | High-resolution transparent PNG logo files. |
| `app-icon/svg/` | Vector app icons and favicon. |
| `app-icon/png/` | Raster app icons and 32 px / 64 px favicons. |
| `fonts/` | Permitted Noto Sans font files and the SIL Open Font License 1.1. |
| `documentation/` | Final PDF brand manual and proof board. |

## Use the right file

| Situation | File |
| --- | --- |
| Standard light background | `logo/svg/camv-logo-primary.svg` |
| Dark Camv Ink or high-contrast background | `logo/svg/camv-logo-reverse.svg` |
| One-colour light-background production | `logo/svg/camv-logo-mono-ink.svg` |
| One-colour dark-background production | `logo/svg/camv-logo-mono-white.svg` |
| Standalone symbol | `logo/svg/camv-emblem-master.svg` |
| Browser favicon | `app-icon/svg/camv-favicon.svg` or `app-icon/png/camv-favicon-32.png` |
| Dark application tile | `app-icon/svg/camv-app-icon-dark.svg` |
| Light application tile | `app-icon/svg/camv-app-icon-light.svg` |

## Approved colour palette

| Name | HEX | Use |
| --- | --- | --- |
| Camv Ink | `#102A5C` | Primary wordmark, headings, dark surfaces, interface anchors. |
| Camv Coral | `#F06C62` | Human accent, right emblem form, selective calls to action. |
| Camv Slate | `#536174` | Supporting text and secondary interface detail. |
| Camv Mist | `#F5F7FA` | Light product surfaces and understated backgrounds. |
| White | `#FFFFFF` | Reverse logo and high-contrast text on Ink surfaces. |

## Typography

Use **Noto Sans Regular (400)** for body copy and **Noto Sans Bold (700)** for headings, navigation, and controlled emphasis. The approved logo wordmark is already converted to vector paths in the supplied SVG files; do not replace it with live type.

The font files included in `fonts/` are licensed under the **SIL Open Font License, Version 1.1**. They may be used, embedded, and redistributed under the license terms supplied in `fonts/OFL-1.1.txt`. The font software may not be sold by itself. See the complete license file for terms.

## Rules that protect the identity

Preserve clear space around the horizontal logo equal to the width of the emblem’s central shared opening. Keep the horizontal signature at least 120 px wide digitally (28 mm in print); keep the standalone emblem at least 20 px digitally (5 mm in print). Do not stretch, rotate, crop, redraw, outline, shadow, gradient-fill, or recolour the logo. Do not separate the two emblem forms.

For complete guidance, see `documentation/Camv_Brand_Manual_v1.pdf`.
